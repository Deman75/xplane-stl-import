# X-Plane STL Import

Локальный инструмент для переноса геометрии авиамодели из STL в **Plane Maker 12**.
Работает как обычная страница в браузере: без установки, сервера и загрузки моделей
в интернет. Текущая версия — **0.5.5**.

## Запуск

Скачайте репозиторий через **Code → Download ZIP**, распакуйте и откройте
`index.html` в настольном Chrome или Edge. Папка `web` должна оставаться рядом
с `index.html`. Node.js для просмотра и экспорта не нужен. Для подготовки
ACF потребуются чистый шаблон из Plane Maker 12 и профили AFL.

## Папка модели

Название выбранной папки становится названием проекта. Пример:

```text
MyAircraft/
├── Fuselage/
│   ├── nose.stl
│   ├── centre.stl
│   └── tail.stl
├── Wing/
│   ├── wing.stl
│   └── ailerons.stl
├── Tail/
│   ├── Horizontal_Stab.stl
│   └── Vertical_Stab.stl
├── Airfoils/                    # необязательно: собственные профили
│   └── my-profile.afl
└── MyAircraft_template.acf      # чистый шаблон Plane Maker 12
```

- Экспортируйте все STL из CAD **в одной системе координат и одном масштабе**.
  Не центрируйте детали отдельно. STL не хранит единицы: выберите их в интерфейсе.
- Части одного фюзеляжа кладите в одну папку. Они объединяются при построении
  наружных обводов; внутренние стенки печатных деталей не должны становиться обводом.
- Имена `Fuselage`, `Wing`, `Horizontal_Stab`, `Vertical_Stab` помогают определить
  назначение. Проверьте роль и группу каждого файла в интерфейсе.
- Элероны в папке `Wing` учитываются в общем контуре крыла. Их автоматическое
  назначение как подвижных поверхностей пока не реализовано.
- Профили можно читать отдельно из установленного `X-Plane/Airfoils`.
  Профиль по STL автоматически не определяется.

## Как получить ACF

1. В Plane Maker 12 создайте **File → New** и сохраните чистый файл как
   `MyAircraft_template.acf` в папке модели. Можно выбрать шаблон отдельно.
2. В импортере выберите папку модели. Проверьте единицы, масштаб, направление
   носа и верх. После изменения осей нажмите **«Пересчитать»**, затем подтвердите
   галочкой, что направления проверены. Подписи осей есть в просмотрщике.
3. Проверьте сечения и восстановление вырезов. При необходимости задайте
   распределение срезов и нажмите **«Снять срезы STL»**. Галочки у узлов несущих
   поверхностей выбирают границы секций ACF.
4. Выберите папку **Airfoils** и назначьте AFL крыла и имеющегося оперения.
   Пустой профиль законцовки означает использование корневого профиля.
5. При необходимости включите **«Записать физические параметры в ACF»**:
   задайте полную массу, центровку (по умолчанию 26% САХ), Vne, мощность
   электромотора на валу, диаметр/шаг/обороты винта и параметры аккумулятора.
   Положение винта задаётся относительно общего нуля модели: X вправо,
   Y вверх, Z назад; координаты вводятся в миллиметрах.
6. При необходимости настройте скрытые опоры для проверки контакта с землёй.
   Оранжевая рамка **«Нужно для ACF»** показывает оставшиеся действия и поля.
7. Нажмите зелёную кнопку **«ACF для Plane Maker · ZIP»**, распакуйте архив,
   откройте ACF в Plane Maker, проверьте результат и сохраните его.

Правая кнопка мыши вращает модель, левая перемещает, колесо меняет масштаб.
Статические OBJ8 исходной геометрии скачиваются отдельной кнопкой.

## Ограничения

Экспорт создаёт **начальное приближение**, а не готовую проверенную лётную модель.
В Plane Maker нужно назначить рули и их ходы, проверить инерцию, силовую установку,
скорости и контакт с землёй. Повторный экспорт создаёт новый ACF из чистого
шаблона и не сохраняет ручные правки ранее экспортированного файла.

Фюзеляж поддерживает до 18 измеренных сечений плюс две точки закрытия торцов
в центрах крайних шпангоутов на тех же Z. Форма крайних шпангоутов сохраняется.
Вырезы восстанавливаются приближённо; неполные обводы требуют проверки.
Основные лимиты поверхностей: крыло — четыре парные секции, горизонтальное
оперение — одна парная, киль — две. Дополнительные панели можно вынести в
Misc Wings. Для корня и законцовки крыла пока требуется одинаковый AFL.

## Файлы проекта

- `index.html` — интерфейс; `web/` — геометрия, экспорт и просмотрщик.
- `tests/` — проверки геометрии, ACF и интерфейса.
- `input/`, `output/`, `reports/` — локальные данные, исключённые из Git.
- [Проверки и устройство проекта](docs/DEVELOPMENT.md).

В репозиторий не включены модели самолётов и файлы из поставки X-Plane.
