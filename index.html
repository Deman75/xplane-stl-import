ГЕОМЕТРИЯ И СЕЧЕНИЯ

Собрать самолёт из деталей

Проверьте масштаб, направления и наружные обводы перед переносом в Plane Maker.

Оранжевая рамка и метка «Нужно для ACF» показывают оставшиеся действия и поля.

01 · Исходные детали

Выберите Project333 целиком. Детали сохраняют общее начало координат CAD.

Файлы пока не выбраны.

02 · Размеры и оси

Измените оси, затем нажмите «Пересчитать». Направление вправо определяется по носу и верху. В экспорте: X вправо, Y вверх, Z назад, метры.

03 · Обводы корпуса

Вырезы под крыло достраиваются по касательным соседних участков. Зелёные линии — восстановленные участки. Разные корпуса держите в разных группах; края без соседних данных не достраиваются.

04 · Профили AFL

Выберите Airfoils из папки X‑Plane. Содержимое читается локально. STL не определяет аэродинамические поляры.

В этой версии для крыла используйте одинаковый профиль в корне и на конце. Поляры не интерполируются автоматически.

05 · Шаблон Plane Maker

Шаблон *_template.acf подхватывается из папки проекта. Нужен File → New → Save As в Plane Maker 12.

Шаблон сохраняет штатные служебные поля. Масса, ЦТ, двигатель и скрытые опоры задаются ниже. Рули назначаются в Plane Maker; их ручные настройки из старого ACF не переносятся.

06 · Масса, центровка и двигатель

Предел по прочности, не крейсерская скорость. Из STL не определяется. В ACF переводится в узлы; нулевое значение блокирует физический экспорт.

САХ рассчитывается по основному крылу вместе с Misc Wings. Отсчёт — от передней кромки, 0% спереди, 100% сзади.

Лопасть, аккумулятор и положение винта

Винт фиксированного шага. Крутка задаётся по шагу 8×8; хорды ниже — редактируемое начальное приближение, не обмер реального винта.

Центр диска винта: X вправо, Y вверх, Z назад, от исходного нуля модели. Нулевые координаты не означают нос самолёта; положение нужно задать вручную.

Полная масса записывается как масса без дополнительной загрузки и топлива. Мощность — механическая на валу, не потребление от аккумулятора. Обороты для построения винта не являются регулятором постоянных оборотов.

07 · Скрытые наземные опоры

Начальная расстановка для Project333: одна опора спереди и две сзади. Координаты редактируются; ЦТ должен быть внутри треугольника опор.

Обжатие 1 мм — начальное приближение для проверки. Радиус контакта 20 мм соответствует текущим колёсам Ø40 мм. Геометрия опор скрыта в X‑Plane, но контакт и сопротивление остаются; дополнительная площадь сопротивления равна 0. Высота опор защищает винт только при достаточном зазоре с учётом наклона и удара.

Редактирование расчётной геометрии

Для каждой детали задайте число и распределение срезов: гуще у краёв или в заданной зоне. Нажмите «Рассчитать позиции», затем «Снять срезы STL». Позиции можно задать вручную через «;». Кнопки +/− добавляют и удаляют срезы. При переносе станции её форма измеряется заново по STL.

Срезы STL и секции ACF — разные уровни: галочки выбирают границы секций, а промежуточные узлы уточняют контур через customize chords. Автовыбор границ учитывает изгибы. Основные пределы: крыло — 4 секции, ГО — 1 парная, киль — 2. «Законцовка отдельно» выносит последнюю секцию в Misc Wings с зеркальной парой для крыла/ГО. Штатный %MAC тогда не учитывает эти законцовки; полная САХ есть в отчёте.

Корпус — до 18 сечений и две автоматические точки закрытия торцов (20 станций ACF). Размеры — мм, X вправо, Y вверх, Z назад. Углы по умолчанию 0°. Общий «Пересчитать» сбрасывает ручные правки; локальное снятие срезов сохраняет правки других деталей и неизменённых станций.

После анализа появятся узлы крыла и станции корпуса.

Результат проекта

Откройте и сохраните ACF в Plane Maker. Крыло экспортируется жёстким: Wing Flex → wing midpoint dihedral increase = 0. Раздел 06 задаёт массу, ЦТ и электромотор; раздел 07 добавляет скрытые опоры. Инерцию, контакт с землёй и назначения рулей нужно проверить до полёта. Новый экспорт создаётся из чистого шаблона и не сохраняет ручные настройки рулей из старого ACF.

Для ACF нужны чистый шаблон, назначенные AFL и подтверждённые оси. Статические OBJ8 скачиваются отдельно, расчётные поверхности видны в самом ACF.
