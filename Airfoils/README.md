# Профили AFL

Стандартные численные таблицы и контуры AFL из папки `Airfoils` X-Plane 12,
формат `1110 Version`. Содержимое `.afl` сохранено без изменений.
Выбор профиля не означает, что он соответствует импортированной модели.

Эти файлы автоматически доступны в списках импортера. Собственные AFL можно
выбрать через «Выбрать папку Airfoils»: файл с таким же именем заменит встроенный
для текущего сеанса. Дубликаты имени внутри выбранной папки считаются ошибкой.

Для обновления встроенного комплекта после изменения файлов выполните из корня:

```sh
node tools/build-bundle.cjs
```

Скрипт обновляет `web/bundled-assets.js`, чтобы профили работали через `file://`
без сервера. Файлы `.afl` и сгенерированный скрипт должны обновляться вместе.
